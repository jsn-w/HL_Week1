# microblitz!

I created a board that interfaces different sensors to help a robot to autonomously navigate a track. This is inspired by the micromouse competition, where a robot navigates a track and solves it as fast as it can.
This board features a Teensy 4.0 microcontroller, which is connected to
- 3-5 time of flight sensors
- two motor drivers
- two motors

The robot stores information about its surroundings into an array and uses an algorithm to find out the fastest way to get from point A to point B.
